How Mate works

Text Mate before you shop. Here’s what you get back.

01

Cashback when you text first

Text Mate before you buy. It sends you the link that tracks your order, and the cashback lands in your balance.

02

Discount codes generated for you

Tell Mate where you’re shopping. It gets you a discount code made just for you.

03

Every package, tracked

A text when it ships and when it’s at your door. Mate can tell your room-mate too.

04

Price drop alerts

Send Mate something you’re eyeing. It watches the price and texts you the moment it drops.

Run the starter on your machine

This GitHub Pages site ships with the open-source Mate starter: a small text agent, a web chat demo, a Twilio webhook stub, and original icons in the mate.fm palette. Demo providers are labeled. They do not pay cashback or issue live merchant codes. 

git clone https://github.com/YOUR-USERNAME/mate.git
cd mate
python -m mate serve
# then open http://127.0.0.1:8080

Intents the starter understands: cashback at <store>, code for <store>, track <number>, watch <url>.
