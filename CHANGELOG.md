# Changelog

All notable changes to this starter are recorded here.

## 0.1.0 — 2026-11-12

- Initial public starter for Mate
- Original 50-icon set in the mate.fm palette, logo, favicon, and 1280×640 social preview
- Stdlib shopping agent with intents for cashback, codes, tracking, and price watches
- Demo providers, clearly labeled, plus an optional OpenRouter fallback
- Web chat demo, Twilio webhook stub, and a price-watcher job
- GitHub Pages landing site in `docs/`, CI workflow, and contributor docs
